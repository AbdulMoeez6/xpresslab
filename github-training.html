Working Online Together

What is GitHub?

In the last training, we learned about Git. Remember, Git is like a special "Save" button or a time machine for your computer work.

Now, we need a place to store these projects online so we can share them and work on them with other people. That place is a website called GitHub (github.com).

Think of it like this:

  • Git is the tool you use on your computer (or in the web editor) to save changes.
  • GitHub is the website where you keep your project folders (repositories) online, like an online filing cabinet for your projects.

It's also a bit like a social network, but instead of sharing photos, people share their code projects!

Why Do We Use GitHub at XpressLab?

Storing Projects Online

All the XpressLab projects you can contribute to are stored safely on GitHub. This means you can access them from any computer with internet.

Sharing and Collaboration

GitHub makes it easy for many people (like you!) to work on the same project without messing things up. It helps manage everyone's contributions.

Tracking Changes

Because the projects use Git, GitHub shows a full history of all the changes made, who made them, and when. It's like a project diary.

Key Parts of GitHub You'll See

When you visit GitHub or follow our Project Guide, you'll interact with these parts of the website:

Repository (Repo)

Just like in Git, this is the online folder for a specific project. It contains all the code files, images, and the history of changes.

Fork / Forking

This is the button you click on GitHub to make your personal online copy of someone else's repository. You need your own copy before you can make changes.

Branch

Like in Git, branches on GitHub let you work on different versions or ideas separately. The main version is often called main or master.

Commit

These are the individual saved snapshots of your work. On GitHub, you can browse through the history of commits to see how the project has changed over time.

Pull Request (PR)

This is how you ask the original project owners to look at the changes you made in your personal copy (your fork) and add them to the main project. It's like sending your finished work for review and approval.

User Account / Profile

You need your own free account on GitHub. This is your identity, where your personal copies (forks) are stored, and how people know who made which changes.

Organization

These are like group accounts on GitHub. XpressLab and its partners (like World Enterprise, Note Hive, etc.) have Organizations where they keep their official project repositories.

Don't Worry About Doing Everything Now! You don't need to click all these buttons yet. This training is just to help you understand what these things are when you see them mentioned in the Project Guide or other trainings.

Ready to See How to Make Changes?

You now know what Git is (the tool) and what GitHub is (the website). The next trainings will show you the actual steps for updating project files!
