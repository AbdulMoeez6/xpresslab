Welcome, Copywriter!

Your Guide to Contributing on XpressLab

This step-by-step guide is designed to help you, even if you've never used tools like GitHub before! Your mission is to find placeholder text (like "Lorem Ipsum") in website code and replace it with great marketing copy. Let's get started!

1Prepare Your Workspace (The 5S Method)

Before you start writing, a clean desk helps you think clearly! It's like tidying up before cooking. We suggest a simple method called 5S:

  • Sort: Remove things you don't need from your desk.
  • Set in Order: Arrange the things you *do* need so they are easy to reach.
  • Shine: Clean your space (wipe down your desk, screen).
  • Standardize: Make this tidying a routine.
  • Sustain: Keep doing it to maintain a productive space!

Don't worry too much about the fancy name, just try to make your workspace comfortable and free of distractions.

👉 Optional: Read more about 5S here

2Find a Project with "Lorem Ipsum" Text

Your first task is to find website code that needs your writing skills. We have several places (called "Organizations" on GitHub) where projects are stored. Look for text like "Lorem Ipsum..." which is just placeholder filler.

How to look:

  1. Click on one of the organization links below (Tip: Hold the `Ctrl` key while clicking to open the link in a new browser tab).
  2. You'll see a list of "Repositories" (these are individual projects). Click on a repository name that sounds interesting.
  3. Look for files ending in .html. Click on them to view the code.
  4. Scan the code for paragraphs of "Lorem Ipsum..." text. If you find some, great! You've found a project to work on.

Once you find a repository (project) with "Lorem Ipsum" you want to fix, move to the next step!

3Make Your Own Copy (Forking)

You can't directly edit the original project. You need to make your own personal copy first. This is called "Forking" on GitHub.

  1. Go to the main page of the repository (project) you chose in Step 2.
  2. Look near the top-right corner of the page. You should see a button labeled "Fork" often with a number next to it.
  3. Click the "Fork" button.
  4. GitHub might ask where you want to fork it. Just choose your own username.

Now you have your very own copy of the project under your GitHub account! All your changes will happen here safely.

4Open the Code Editor (The Easy Way!)

Now, let's open the code so you can edit it. There's a super easy way to do this right in your web browser!

  1. Make sure you are on the webpage for your personal copy (your fork) of the repository. The web address should include your GitHub username.
  2. Click anywhere on the white background of the page (just make sure you don't click a link).
  3. Press the period key (.) on your keyboard. Just tap it once.

Magic! A code editor (it looks like a program called VS Code) should appear right inside your browser tab. You can now see all the project files and are ready to edit them.

No Downloads Needed: This method uses a web-based editor ([VSCode.dev](https://vscode.dev/)), so you don't need to install any software on your computer.
Alternative (For Advanced Users): If you prefer working offline, you can download [GitHub Desktop](https://desktop.github.com/) and your own copy of [VS Code](https://code.visualstudio.com/) to edit files on your computer. This guide focuses on the easier web method.

5Preview Your Changes (Optional: Live Server)

When you change text in the code, you'll want to see how it looks on the actual webpage. The web editor you opened in Step 4 might have a basic preview, but sometimes it helps to see it more accurately.

If you chose the Alternative Method in Step 4 and are using VS Code installed on your computer, you can use an extension called "Live Server" to see a live preview:

  1. In your desktop VS Code, look for an icon on the left side that looks like square puzzle pieces (Extensions). Click it.
  2. In the search bar that appears, type `Live Server`.
  3. Find the one by "Ritwick Dey" and click the blue "Install" button.
  4. Once installed, go back to your file list (usually the top icon on the left, looks like paper sheets).
  5. Find the .html file you plan to edit. Right-click on its name.
  6. Choose "Open with Live Server" from the menu.

This will open the webpage in your browser, and it will automatically refresh whenever you save changes in VS Code!

If you are using the web editor (from pressing .), you might not need Live Server, as previewing might be built-in or you can simply save and refresh manually if needed. Focus on the writing first!

6Rewrite the Content using an AI Helper (GPT)

Now for the fun part: replacing the "Lorem Ipsum" text! You can use an AI writing assistant(like ChatGPT, Gemini, Claude, GitHub Copilot, or others – these are often called "GPT" models) to help you generate new marketing copy.

Which AI Tool to Use?

  • Use any AI tool you are comfortable with.
  • For rewriting large sections or whole pages, simpler models might work well (like GPT-3.5 or similar).
  • For important headlines or short phrases, more advanced models (like GPT-4 or similar) might give better results.
  • The goal is good quality writing that fits the project.

How to Use the AI:

  1. Find the .html file you want to edit in the code editor (from Step 4).
  2. Select all the code in that file (Tip: Click inside the code, then press `Ctrl+A` on your keyboard).
  3. Copy the selected code (Tip: Press `Ctrl+C`).
  4. Go to your chosen AI writing tool in another browser tab.
  5. First, paste the instructions (the prompt) below into the AI chat.
  6. Second, paste the HTML code you copied right after the instructions.
  7. Ask the AI to rewrite the placeholder text based on the instructions.

Copy and Paste These Instructions (Prompt) into your AI Tool FIRST:

### Role:
You are an expert copywriter tasked with editing HTML code. Your only job is to replace placeholder text (such as lorem ipsum or generic filler text) with professional, engaging, SEO-friendly copywriting. You must strictly adhere to the following guidelines:

### Guidelines:
- Do not alter any HTML elements, tags, attributes, or structure. Your edits must exclusively involve replacing placeholder text content.
- Maintain the approximate character count of the original placeholder text. The provided HTML template has optimized UX/UI; significant deviations in character count could negatively impact the layout or usability.
- Ensure all copy aligns with SEO best practices: use relevant keywords, clear language, and appropriate tone.
- Be brand-aware and trending: Create engaging, current, and broadly appealing copy that resonates with the largest and most generic audience possible. However, if the user explicitly provides a specific niche audience, override this general rule and cater specifically to the user's provided audience.
- Follow brand guidelines closely. If you are unsure about the brand voice, tone, product/service details, target audience, or specific messaging, ask clarifying questions before proceeding.

### Workflow:
1. Review the provided HTML code carefully.
2. Identify all placeholder or lorem ipsum text elements.
3. If the user has not provided the following business classification codes, ask the user to provide them before proceeding: - NAICS (North American Industry Classification System) - SIC (Standard Industrial Classification) - PSC (Product Service Code) - SIN (Special Item Number)
These codes will help you make the most informed decisions around the copy, services, and branding.
*(User Note: If you don't know these codes for the project, tell the AI you don't have them and ask it to proceed with general best practices for the industry described in Step 2).*
4. If necessary, ask additional relevant clarifying questions to understand the brand, product/service, target audience, voice, tone, and SEO requirements.
5. Replace placeholder text with appropriate copywriting.
6. Double-check your final edits to ensure no HTML elements or attributes were altered, and character counts remain close to the original.

### Output Format:
- Provide back the FULL HTML code with the placeholder text replaced, allowing the user to easily copy/paste your provided HTML to replace the entire original HTML file.
- Do not provide partial HTML or snippets. Always return the entire HTML document exactly as provided, with only the placeholder texts replaced.

### Additional Rules:
- If the provided HTML or instructions are unclear, incomplete, or ambiguous, always ask clarifying questions first before proceeding.
- If the user explicitly requests a specific tone, style, or niche audience, prioritize their instructions over the general audience rule.
- Always ensure you have the necessary business classification codes (NAICS, SIC, PSC, SIN) provided by the user before proceeding, *unless* the user explicitly tells you they don't have them.

---
Now, here is the HTML code I need you to edit:

After pasting the prompt, paste the HTML code you copied right below it in the AI chat window and hit Enter/Send.

AI Isn't Perfect! Always read the text the AI gives you. Does it make sense? Does it sound good? You are the human expert – fix any mistakes the AI makes!
Learn Copywriting: AI is a tool, but understanding basic copywriting helps a lot. See the training links at the end of this guide!

7Put the New Text into the Code Editor

Once the AI gives you the rewritten HTML code:

  1. Carefully select all the code the AI provided in its response. Make sure you get everything from the very beginning () to the very end ().
  2. Copy the selected code (Tip: `Ctrl+C`).
  3. Go back to the browser tab with your code editor (from Step 4).
  4. Click inside the code editor for the file you are working on (e.g., index.html).
  5. Select all the *old* code currently in the editor (Tip: `Ctrl+A`).
  6. Paste the new code you copied from the AI, replacing the old code (Tip: `Ctrl+V`).
  7. Save the file (Tip: `Ctrl+S`, or look for a File > Save menu option).

You've now updated the file with the AI-generated copy!

8Check Your Work!

Now, let's make sure everything looks okay.

  • If you set up Live Server (Step 5), your preview browser tab should have updated automatically. Check it now.
  • If you are using the web editor, saving the file (Ctrl+S) might update a preview pane, or you might need to find a preview option.
  • Look carefully:
    • Did any parts of the webpage break or look strange?
    • Is the new text easy to read?
    • Does it make sense for the project?
    • Did you miss any "Lorem Ipsum"?
  • If something is wrong, go back to Step 6 or 7 and try again, or manually fix small errors directly in the code editor.

9Save Your Progress (Committing)

Think of this like saving your game. In GitHub language, it's called "Committing". It saves a snapshot of your changes with a note explaining what you did.

If you are using the web editor (from pressing .) or desktop VS Code:

  1. Look on the left side of the editor for an icon that looks like branching lines ( ). This is usually the "Source Control" or "Git" panel. Click it.
  2. You should see the file(s) you changed listed there.
  3. Above the list, there's usually a box labeled "Message". Type a short description of your changes here. Be clear and concise.
    Example: Updated marketing copy on homepage section
    Example: Replaced Lorem Ipsum in about page
  4. Click the "Commit" button (it might look like a checkmark or say "Commit").
  5. It might ask if you want to "stage" changes first. Usually, you can just say yes or click "Commit".
  6. You might also see a "Sync Changes" or "Push" button appear after committing. Click that too – this uploads your saved changes from the editor back to your personal copy on the GitHub website.

Your changes are now saved to your personal copy (your fork) on GitHub!

10Send Your Changes for Review (Pull Request)

Okay, last step! You need to ask the owners of the *original* project to look at your changes and add them to the main project. This is called creating a "Pull Request" (or PR).

  1. Go back to your personal copy (your fork) of the repository on the GitHub website (not the editor, the regular website view).
  2. You might see a yellow bar near the top saying you recently pushed changes, with a button like "Compare & pull request". If you see it, click it!
  3. If you don't see that bar, look for a tab or button labeled "Contribute" or "Pull requests". Click it, then look for a green button like "New pull request".
  4. GitHub will show you the changes you made. Make sure it looks correct.
  5. You'll need to write a title and a short description for your Pull Request.
    • Title: Briefly say what you did (e.g., "Updated Homepage Copywriting").
    • Description: Explain the changes you made. You can even ask your AI helper (GPT) to write a quick summary for you based on the changes! Mention that you replaced Lorem Ipsum with marketing copy.
  6. Click the green button that says "Create pull request".

That's it! You've sent your work to the project maintainers.

🎉 Congratulations! 🎉

You've successfully submitted your first contribution as a copywriter using XpressLab and GitHub! That wasn't so hard, was it?

The project owners will now review your Pull Request. They might approve it, ask for changes, or give you feedback. Keep an eye on your GitHub notifications.
