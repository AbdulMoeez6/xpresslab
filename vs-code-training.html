XpressLab Beginner Guide (Editing on Your Computer)

Welcome to XpressLab – a place where you can learn, grow, and contribute to real projects, even if you’ve never used a computer much before.

This guide shows you how to make changes to project files using programs installed on your own computer. It involves a few setup steps, but it's a powerful way to work!

?Tools You Will Need (Free Programs)

For this method, you need to install a few free programs on your computer if you haven't already. Click the links to download them.

Stop and Install First! If you haven't installed Git and VS Code, please do that now. Double-click the downloaded files and follow the on-screen instructions, choosing the default options. Ask for help if you get stuck!

1Clean Your Workspace

Let's get organized before starting:

  1. Close programs you don't need.
  2. Open your web browser (like Chrome or Firefox).
  3. Have this guide open in one browser tab.
  4. Have the GitHub website open in another tab, and make sure you are logged in.

3Make Your Online Copy (Fork)

First, make your personal copy of the project on the GitHub website.

  1. Go to the main page of the project you chose on GitHub.
  2. Find the Fork button (usually top-right with a icon) and click it.
  3. GitHub might ask for a name. You can usually keep the suggested name unless you've forked this project before.
  4. Crucial Step: If you see an option like "Copy the main branch only", uncheck it! We need all branches. If you see a dropdown to select a branch *to fork from*, try to choose gh-pages if it's there. Otherwise, just proceed.
  5. Click the green Create fork button. Wait a moment while GitHub copies the project to your account.

4Download Your Copy to Your Computer (Clone)

Now, let's get that online copy onto your computer.

  1. Go to the webpage for YOUR forked copy on GitHub (the address bar should show github.com/your-username/project-name).
  2. Make sure the branch dropdown button (top-left, below the project name) shows gh-pages. If not, click it and select gh-pages.
  3. Click the green Code button.
  4. In the little window that appears, make sure HTTPS is selected. Copy the web address link (it ends in .git) by clicking the copy icon next to it.
  5. Open the VS Code program on your computer.
  6. Open the VS Code Terminal: Click "Terminal" in the top menu, then "New Terminal". A typing area appears at the bottom.
  7. Click inside the Terminal area. Type git, space, clone, space, then Paste the link you copied (Ctrl+V or Cmd+V or Right-click > Paste). It should look like:
    git clone https://github.com/your-username/project-name.git
  8. Press the Enter key. Wait for Git to download the files. It will print some messages and stop when done.
  9. Open the Downloaded Folder:
    • In VS Code, click File (top-left menu) > Open Folder...
    • Find the new folder on your computer that has the same name as the project (e.g., `project-name`). It's often in your main user folder or Documents.
    • Click the folder once to select it, then click the Open or Select Folder button.

VS Code will reload and show the project files on the left side panel (the Explorer).

5Check Your Working Area (Branch: gh-pages)

Let's double-check you're set to work on the website files.

  1. Look at the bottom-left corner of the VS Code window. You should see the branch name (like gh-pages).
  2. If it says gh-pages, you are perfect! Go to the next step.
  3. If it says something else (like main), click on that name.
  4. A list will appear at the top. Click on gh-pages in that list.

Now the bottom-left should show gh-pages.

6Find and Open the File to Edit

Locate the specific webpage file you want to change.

  1. Look at the list of files and folders in the Explorer panel on the left side of VS Code.
  2. Find the file ending in .html (like index.html or about.html).
  3. Double-click the filename to open it in the main editor area.

7See Changes Live (Optional: Live Server)

Want to see how your changes look on a webpage instantly? Use Live Server.

  1. Install it if you haven't: Click the Extensions icon ( four squares) on the left bar, search for Live Server, find the one by Ritwick Dey, click Install. Then click the Explorer icon ( top-left) to return to your files.
  2. In the Explorer panel, right-click on the .html file you are editing.
  3. Choose "Open with Live Server".

Your web browser will open the page. It should update automatically when you save the file in VS Code.

8Replace the "Lorem Ipsum" Text

Now you can edit the content.

  1. In the VS Code editor, find the "Lorem Ipsum" placeholder text.
  2. Select the text you want to replace.
  3. Type your new text, or use an AI helper:
    • Go to ChatGPT (or similar) in your browser.
    • Ask it to rewrite the text (e.g., Rewrite for a non-profit website: "Lorem ipsum...").
    • Copy the AI's text.
    • Back in VS Code, paste (Ctrl+V / Cmd+V) over the selected "Lorem Ipsum".
  4. Repeat for all needed text changes in the file.
  5. VERY IMPORTANT: Save the file! Click File > Save in the top menu, or press Ctrl+S (Windows) / Cmd+S (Mac).

9Save Your Changes Snapshot (Commit)

Tell Git to save a record of the changes you just made.

  1. Click the Source Control icon ( branching lines) on the far left bar of VS Code.
  2. You'll see the file(s) you changed listed.
  3. In the Message box at the top of this panel, type a short description (e.g., Updated about page text).
  4. Click the Commit button (often a checkmark ).
  5. If asked about "staging", click "Yes".

Your changes are saved locally on your computer.

10Upload Saved Changes to GitHub (Push/Sync)

Send your saved changes from your computer up to your online GitHub copy.

  1. In the same Source Control panel (), look for a button at the bottom status bar or top of the panel labeled "Sync Changes" or "Publish Branch" (might show arrows or a cloud ).
  2. Click that button.
  3. The first time, VS Code might ask you to log into GitHub. Follow the steps.
  4. Wait for the upload to complete.

Your changes are now online in your GitHub fork!

11Ask to Add Your Changes (Pull Request)

Last step! Go back to the GitHub website to send your work for review.

  1. Open your web browser and go to the page for your forked repository on GitHub (github.com/your-username/project-name).
  2. You should see a yellow bar: "gh-pages had recent pushes..." Click the green Compare & pull request button.
  3. (If no yellow bar: Click the Pull requests tab > New pull request button).
  4. Double-Check the Branches: Make sure it says it wants to merge changes from your fork's gh-pages branch into the original project's gh-pages branch.
  5. Write a clear title and short description explaining your changes.
  6. Click the green Create pull request button.

What Happens Next?

The project team will get a notification about your Pull Request. They will look at your changes.

  • They might approve it and add your work to the main project!
  • They might ask you questions or suggest small changes (you'll see comments on the Pull Request page on GitHub).
  • Don't worry if they ask for changes, it's part of learning!

Final Tip

Using VS Code takes a bit more setup but gives you more control, especially for bigger projects. Take your time, follow the steps, and don't hesitate to ask for help in the community if you get stuck.

You learned a valuable new skill! Keep practicing!
