Easy Contribution Method

How to Update Files on the GitHub Website

Welcome! This guide shows you the easiest way to change text in our projects. You don't need to download any special programs – you can do it all right here in your web browser on the GitHub website!

This method is perfect for fixing typos, replacing "Lorem Ipsum" text, or making small updates.

1Get Ready: What You Need First

Before you start editing, make sure you have already done these things from the Project Guide or previous trainings:

  • You have a free GitHub account and you are logged in.
  • You have found an XpressLab project on GitHub that has "Lorem Ipsum" text you want to replace.
  • You have created your own personal online copy of that project by clicking the Fork button.

If you haven't done these steps, please go back to the Project Guide first!

Remember: You always make changes in your copy (your fork) first, never directly in the original XpressLab project.

2Go to YOUR Copy (Your Fork)

Let's find your personal copy of the project on the GitHub website.

  1. Go to the main GitHub website: github.com
  2. Make sure you are logged in. You should see your profile picture or icon in the top-right corner.
  3. Click on your profile picture/icon in the top-right corner. A menu will appear.
  4. Click on "Your repositories".
  5. You will see a list of projects. Find the one you "Forked" earlier (it will have the name you gave it, and might say "forked from..." below the name).
  6. Click on the name of your forked project to open its page.

You are now looking at your personal copy of the project!

3Choose the Right Working Area (Branch: gh-pages)

Projects often have different working areas, like separate folders for different ideas. For the website changes, we usually work in an area called gh-pages.

  1. On your forked project page, look near the top-left, below the project name. You should see a button that shows the current branch name (it might say main or something else, often with a icon).
  2. Click on this branch button. A dropdown list will appear.
  3. Look for gh-pages in the list and click on it.
  4. The page will refresh. Now, make sure the button shows gh-pages.
Very Important: Always make sure you are in the gh-pages branch before you start editing files for website content! If you edit in the wrong branch, your changes might not show up correctly.

4Find and Open the File to Edit

Now, let's find the specific page (file) you want to change the text on.

  1. Look at the list of files and folders shown on the main part of the page (make sure you're still in the gh-pages branch!).
  2. Website pages usually end with .html (for example: index.html, about.html, contact.html).
  3. Find the .html file that you saw the "Lorem Ipsum" text in earlier (or the one you want to edit).
  4. Click on the name of the file (e.g., click on index.html).
  5. You will now see the content of that file. It will look like computer code.
  6. Look near the top-right corner of the code view. You should see a small pencil icon (). This is the "Edit" button.
  7. Click the pencil icon ().

You are now in the GitHub online editor! You can type directly into the text box that appears.

5Replace the "Lorem Ipsum" Text

Time to do the writing!

  1. Scroll through the code in the editor box. Find the paragraphs that contain the "Lorem Ipsum" text.
  2. Select the entire chunk of "Lorem Ipsum" text you want to replace with your mouse (click and drag over the text).
  3. You can either:
    • Type your new text directly: Just start typing, and it will replace the selected "Lorem Ipsum".
    • Use an AI Helper (Recommended):
      1. Open a new browser tab and go to your favorite AI tool (like ChatGPT).
      2. Ask the AI to rewrite the "Lorem Ipsum" text. You can use a simple prompt like:
        Please rewrite this placeholder text for a website about [briefly describe the project, e.g., 'startups' or 'home design']: "[Paste the Lorem Ipsum text here]"
        (Remember to replace the parts in square brackets!)
      3. Copy the new text the AI gives you.
      4. Go back to the GitHub editor tab.
      5. Make sure the old "Lorem Ipsum" text is still selected.
      6. Paste the new text you copied from the AI (Tip: Press `Ctrl+V` on your keyboard).
  4. Repeat this process for all the "Lorem Ipsum" sections you want to change in this file.
Be Careful! Only change the text content. Try not to accidentally delete any of the strange symbols like 
    <p> or </p> or <div>
. These are HTML code tags that structure the page. Just replace the words between them.

6Check and Save Your Changes (Commit)

Once you've replaced the text, let's save your work.

  1. Near the top of the editor, you might see a tab called "Preview changes". Click it to get a rough idea of how your changes look. (It might not look exactly like the final website here). Click back to the "Edit file" tab when done previewing.
  2. Scroll down below the editor box. You will see a section called "Commit changes".
  3. There are two text boxes here.
    • The first (larger) box is for a short title for your save. Type something simple that describes what you did. Examples: Update homepage text Replace Lorem Ipsum on About page Fix typo in contact section
    • The second (smaller) box is optional. You can add more details if you want, but the title is usually enough for simple text changes.
  4. Below the text boxes, make sure the option "Commit directly to the gh-pages branch." is selected. (It usually is by default).
  5. Click the green button that says "Commit changes".

Great! You have successfully saved your changes to your personal copy (your fork) of the project on GitHub.

7What's Next? The Pull Request!

You've updated the file on your copy of the project. Now you need to tell the original XpressLab project owners about your changes so they can add them to the main project.

This next step is called creating a "Pull Request" (PR). You learned about this in the GitHub Basics training. You essentially send a request saying "Please pull my changes into your project!"

Go back to the main page of your forked repository on GitHub. You might see a yellow bar suggesting you create a Pull Request. Follow the steps outlined in the Project Guide (Step 8) to submit your Pull Request correctly (remembering to compare the gh-pages branches!).

You've learned the easiest way to contribute!

This method of editing directly on the GitHub website is fantastic for quick text changes. For more complex work, you might explore using VS Code later.
